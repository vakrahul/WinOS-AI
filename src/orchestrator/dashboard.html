🔒 Zero-Implicit-Trust Security Model

The AI model is an untrusted advisory client. All planned actions, tool calls, filesystem operations, and process launches are intercepted by an independent host-side security engine outside the LLM's prompt context.

High-impact operations (e.g. system file modifications or shell execution) require cryptographically generated 256-bit CSPRNG approval nonces with a 300-second expiration window.

🔑 Hardware Credential Vault (Windows DPAPI)

API keys and credentials never live in plaintext on disk or in `.env` files. Secrets are sealed via Microsoft Windows Data Protection API (`CryptProtectData`), bound to the machine user credentials and TPM chip.

Keys are decrypted in-memory only during outgoing HTTP request dispatch.
